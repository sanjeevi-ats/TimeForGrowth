## 🎨 Color Scheme

| Element | Color | Usage |
|---------|-------|-------|
| Background | `#FFFFFF` (White) | Main page background |
| Text (Primary) | `#000000` (Black) | Headings, main text |
| Text (Secondary) | `#666666` (Gray) | Descriptions, subtitles |
| Borders | `#E0E0E0` (Light Gray) | Card borders, dividers |
| Accents | `#000000` (Black) | Buttons, icons |
| Hover States | `#1a1a1a` (Dark Gray) | Interactive elements |

## 🔲 Component Sizes

### Hero Section
- Height: 85vh (viewport height)
- Max Width: 80rem (1280px)
- Padding: 5rem vertical, 1rem-2rem horizontal

### Product Cards
- Grid: 2 columns (mobile), 4 columns (desktop)
- Gap: 1rem
- Aspect Ratio: Square

### Category Cards
- Grid: 2 columns (mobile), 4 columns (desktop)
- Gap: 1rem
- Aspect Ratio: Square
- Background: Black
- Border Radius: 0.5rem

### Wellness Cards
- Grid: 1 column (mobile), 3 columns (desktop)
- Gap: 1.5rem
- Padding: 1.5rem
- Border: 1px solid #E0E0E0

## 🎯 Key Design Principles

1. **Clarity**: Clean, uncluttered layout with clear hierarchy
2. **Consistency**: Uniform spacing, typography, and color usage
3. **Accessibility**: High contrast, readable fonts, proper semantic HTML
4. **Responsiveness**: Works seamlessly on all device sizes
5. **Performance**: Optimized images, minimal animations
6. **User-Focused**: Content-first approach, clear CTAs

---

## ✨ Interactive Elements

### Buttons
- **Primary**: Black background, white text, rounded corners
- **Secondary**: White background, black border, rounded corners
- **Hover**: Scale up slightly, shadow effect

### Form Inputs
- **Style**: Border-based, rounded corners
- **Focus**: Black border, ring effect
- **Placeholder**: Light gray text

### Cards
- **Hover**: Border color change, shadow effect, slight scale
- **Transition**: Smooth 0.3s duration
