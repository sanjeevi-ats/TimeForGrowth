## 🎬 Animation Timeline

```
Page Load:
  0ms   → Hero heading fades in
  150ms → Hero description fades in
  300ms → CTA button fades in
  450ms → Category icons fade in
  
Scroll:
  On intersection → Products fade in (staggered)
  On intersection → Categories fade in (staggered)
  On intersection → Wellness cards fade in (staggered)
  
Hover:
  0ms   → Card border changes
  300ms → Card scales up
  300ms → Shadow appears
```
